STYLE: this is a MOCK SCREEN of the user interface of the same game as Image 1: a dark-fantasy top-down pixel-art dungeon crawler. One complete 16:9 landscape frame (1920x1080 layout), the whole screen edge to edge, nothing outside it. Match Image 1 exactly in rendering: every pixel a hard square of one flat colour on one even grid, the UI drawn on the same pixel grid as the game art (one art pixel is a 3x3 block of screen pixels), no anti-aliasing, no blur, no smooth gradients, no vector look, no glossy 3D buttons, no drop shadows from a web design; soft transparency is done with a 1-pixel checker dither. Low-key and muted like Image 1, 1-pixel dark outline (#060506 or #231010) on every frame and icon. Any game scene or hero visible behind or inside the screen is painted like Image 1: same camera, same chunky stone walls, same hero (red cape, steel breastplate, sword), lit by warm torches with deep shadow.
GOAL: the interface of a finished, grown-up commercial pixel-art RPG, deliberate and restrained, not a hobby project: strict alignment, a clear type hierarchy, generous consistent margins, one frame language and one accent colour used everywhere, small and calm controls, no oversized buttons, no clip-art, no random decoration, no rainbow of colours. Original design only: do not imitate the screens, panels, fonts or art of any specific existing game.
TEXT RULES: absolutely no game title, no logo, no studio name, no watermark. Labels are short, sparse, plausible Russian words in a crisp retro bitmap pixel font with Cyrillic letters (chunky, one pixel stroke, even spacing, no italic), set small; where a line of body text would be long, draw it as unreadable pixel glyph marks of the same font rather than inventing words. Numbers only where listed. No English words except keys such as Esc, E, J.

DIRECTION B, "codex and leather" (a hand-made book). The interface looks like an old bound book and loose pages: aged parchment (#c8b89a, shadows #a08a62, stains #6b5a3e) for reading surfaces with dark brown-black ink text (#231010) and red-ink headings (#73140d); dark leather panels (#552f25, #733a21 highlight, #36120f shadow) with a row of fine stitching, brass corner caps and clasps (#9f5116 / #e2881e), ribbon bookmarks as tabs, red wax seals (#73140d, #4f150c) as the selected marker and as confirm buttons. Dark HUD plates are leather with stitching and small parchment tags for labels; health and mana are glass vials filled with red and blue liquid set in brass, not flat bars. Rounded organic corners with small hand-drawn flourishes, thin ink rules between rows, never straight machine borders. The single accent colour is oxblood red with brass gold; rarity colours only on items.

SCREEN: the save list (Загрузить игру) over the dimmed menu backdrop. One centred window about 1100x700 px. Header: Загрузить игру. A vertical list of six save slots, five filled and one empty (Пусто), each row about 90 px high with: a small class portrait icon (warrior, mage, archer), a class name, a level mark like Ур. 12, a floor mark like Этаж 7, the date like 08.11.2026 and a play time like 3 ч 40 мин. The second row is selected and a small preview strip of its last scene is shown on the right side of the window with a Загрузить button and a small Удалить button under it. A confirmation line popup is visible in a corner as a small panel «Удалить сохранение?» with two small buttons Да and Нет. Bottom: Назад.

Layout: rows are labelled leather-bound volumes or hanging parchment tags on strings, the selected one pulled out slightly, the preview is a small framed painting, the confirmation is a small torn note pinned over with a red wax Да seal and a plain Нет.
