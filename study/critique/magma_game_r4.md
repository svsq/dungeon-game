## Топ исправлений по влиянию

### 1. Гнездо: тлеющих меньше, но цепь взрывов по-прежнему бьёт 65–69 % за 1,5 с, а иногда два взрыва в один тик
- **ЧТО.** `sim.js` `blast()`, стр. ≈ 345–347. Взрыв сразу поджигает соседа в радиусе (`fuse(S, R, o)`). Двое, подожжённые в один тик (`fuse` у обоих 5,34 с, а затем 8,48 с), взрываются тоже в один тик.
- **ПОЧЕМУ.** Живые прогоны (`frames/game_r4/*/log.json`, разбор `live_runs.txt`):

  | Прогон | Взрывы |
  |---|---|
  | река s3 f3 | 272 + 272 — оба в 9,29 с, 66 % здоровья в одном кадре |
  | террасы s1 f2 | 5,19 / 5,99 / 6,64 с — 3 × 223 за 1,45 с, 69 % |
  | пропасть s27 f2 | 7,13 / 7,93 / 8,46 с — 3 × 220 за 1,33 с, 65 % (`chasm_s27_f2/a_006.png`: 449 / 1008 на 7-й секунде этажа) |

  - Смертей в гнезде больше нет (было: 4 взрыва — смерть за 9,5 с), но цепь из 2–3 взрывов в 3 гнёздах из 4.
  - Два взрыва в один тик — это один удар на 66 %, его не прочитать двумя кольцами: кольца совпадают.
  - 3 гнезда из 46 стоят в 15 клетках от точки появления (`nestpos_40.txt`; s1 f2 — 12 клеток, s3 f3 — 14). Игрок входит в них на 3-й секунде этажа.
- **КАК.**

  - Числа урона — в 414.

### 2. Река: на охраняемой переправе ещё и больше прицельных серий — для того, кто читает метки, переправа с камнями всё равно дешевле
