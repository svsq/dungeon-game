## Оставшиеся исправления по влиянию

### 1. Открытая боковая створка — темнее и сильнее приоткрыть (средне)
- **ЧТО:** `door_l_open` x 877–958 y 439–555 кадра; `door_r_open`. `scene.js`, ветка `if (side)`, `p > 0`:
  `ux = s * Math.sin(1.3) * DOOR.w, uy = Math.cos(1.3) * DOOR.w`, `grade: [0.62, 0.8, 0, 1]`.
- **ПОЧЕМУ:** анфас-полотно с аркой и кольцом — это силуэт «закрытой двери». Отличить его могут только тень и скос. Тень не
  работает: L 38.8 при 39.8 у закрытой двери. Скос 16.6 px на 62 px — это 15°, на зуме 1 почти не виден.
- **ИЗМЕНЕНИЕ:**
  ```js
  const ang = 1.05, ux = s * Math.sin(ang) * DOOR.w, uy = Math.cos(ang) * DOOR.w;   // 60°: скос 31 px, ширина 54
  ... u: { alpha: p, grade: [0.45, 0.7, 0, 1] }
  ```
  Добавить тёмный клин между свободным краем и стеной: `L.shadow` вытянуть вдоль низа полотна
  (`L.shadow(X + ux/2, fy + uy/2 + 2, Math.abs(ux)/2 + 4, 6, 0.6 * p)`). Цель: L полотна ≤ 0.7 от закрытой двери (≤ 28)
  и видимый наклон нижнего края. Эту цель внести в QA-состояние `door_l_open` проверкой яркости.

### 2. Засов должен держаться за камень и отличаться от полос (средне-мелко)
- **ЧТО:** `door_bar` y 523–536, `door_bar_l`; `locks()` — `len = DOOR.w + 4` для анфаса и `ew * 1.3` для ребра.
- **ПОЧЕМУ:** брус той же яркости, что и полосы полотна (L 52 при дереве 55), и лежит в их ряду. Состояние «заперто рычагом»
  отличается от «не заперто» одной лишней полосой. На полотне ребром конец бруса висит в воздухе за дальним краем.
- **ИЗМЕНЕНИЕ:** на анфасе `len = DOOR.fw * 0.78` (≈92 view px), чтобы скобы легли на камни арки (у нижней двери без арки —
  `DOOR.w + 16` и тени под скобами). Брус опустить на ~6 px ниже средней полосы, чтобы он не совпадал с ней:
  `cy = foot - DOOR.h * 0.38`. Высветлить его, сделав холоднее и светлее: `u: { grade: [1.25, 1, 0, 1] }`. На полотне ребром
  `len = ew * 0.95`: брус внутри полотна, без свеса.

## Мелочи
- Кроссфейд анфас → ребро даёт двойное полупрозрачное полотно на p≈0.3–0.7. Можно перекрыть быстрее: `alpha` анфаса = `1 − SS(0.2, 0.5, p)`,
  ребра — `SS(0.4, 0.7, p)`.
- Висячий замок на полотне ребром стоит анфас. Сдвиговая матрица по `E.band`, как у засова, посадит его на плоскость полотна.
- Закрытая нижняя дверь (`door_d`): тёмная полоса проёма 3–4 px по бокам полотна сделала бы её дверью «в стене», а не доской перед стеной.
- Плотность исходника двух ракурсов отличается в 1.45 раза (6.2 против 9.0 src px на view px). Сейчас это скрыто сеткой 2×2,
  при перегенерации листа стоит выровнять.
- Верхняя дверь в арке (`door_u`, `door_u_open`) остаётся образцом, её не трогать.
