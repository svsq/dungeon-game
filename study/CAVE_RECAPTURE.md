## Воспроизведение

Из корня проекта:

```sh
python3 tools/caverecapture.py
python3 tools/cavereviewpack.py
```

`--resume` у первой команды пропускает уже успешные этапы; применять только на том же checkout без изменений исходников. GPU-проверки идут последовательно; вода/FPS снимается отдельно от других браузерных прогонов. Каждый этап сохраняет команду, UTC-время начала, exit code и отдельный лог в `frames/cave_recapture/`. Неуспешный этап не мешает сохранить остальные материалы; упаковщик проверяет состав и допустимые известные ошибки перед сборкой. Для работы нужны проектный Playwright/Chromium в `~/.claude/skills/ref2game/scripts` и Python с Pillow/NumPy/SciPy.
