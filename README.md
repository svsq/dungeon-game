# Глубины Крипты

![Глубины Крипты](docs/cover.png)

Тёмное фэнтези-подземелье в пиксель-арте: вид сверху 3/4, процедурные этажи, лут, способности и прогресс между забегами.
Игра работает в браузере на собственном движке WebGL2 без сборки и зависимостей.

## Об игре

- **8 этажей, 4 биома:** Подземелье (1–2), Крипты (3–4), Огненные глубины (5–6), Чертоги (7). На 8-м этаже, в Троне Демона, ждёт Повелитель Демонов.
- **Боссы глав:** Королева пауков на 2-м этаже, Верховный некромант на 4-м, Владыка горна на 6-м. Арены закрываются до победы; Повелитель Демонов в третьей фазе сочетает их приёмы.
- **Процедурная генерация:** на каждом этаже новая карта с комнатами, коридорами и особыми комнатами (крипта, магический зал, сокровищница, безопасная комната, лавка), ловушками и лавой.
- **Враги:** скелеты, гоблины, пауки, культисты, призраки, демоны и их элитные версии. У всех анимированные риги.
- **Лут:** оружие и броня в 8 слотах, 5 уровней редкости от обычного до легендарного, случайные свойства, зелья и свитки.
- **Развитие:** уровни, характеристики (сила, ловкость, интеллект, живучесть) и три способности: Вихрь клинка, Огненный шар, Магический щит.
- **Мета-прогресс:** осколки душ, собранные за забег, тратятся на постоянные улучшения у Алтаря душ.
- **Сохранения:** забег и мета-прогресс хранятся в `localStorage`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| ЛКМ | атака в сторону курсора |
| 1 2 3 | способности |
| Пробел | рывок |
| Q / R | зелье здоровья / маны |
| E | действие: открыть сундук, говорить с торговцем, спуститься по лестнице |
| I | экран героя |
| Esc | пауза |

Геймпад (R-08): работает дополнительно к клавиатуре — как только пад активен, подсказки в игре показывают кнопки.

| Кнопка | Действие |
|---|---|
| Левый стик | движение |
| Правый стик | прицел (курсор) |
| RT | атака (удержание), клик по кнопке в меню |
| X / Y / LT | способности 1 / 2 / 3 |
| B | рывок (в бою), назад (в меню) |
| A | действие (E), подтвердить в меню |
| LB / RB | зелье здоровья / маны |
| Select (≡) | экран героя |
| Start (☰) | пауза |
| Крестовина | навигация по меню |

## Запуск

Нужен любой статический HTTP-сервер: WebGL не загружает текстуры по `file://`.

```sh
git clone https://github.com/svsq/dungeon-game.git
cd dungeon-game
python3 -m http.server 8930
```

Затем откройте <http://127.0.0.1:8930/live/index.html>. Пока не нажата клавиша, идёт демо-заставка.

Открытая страница сама перезагружается при изменении исходников, а состояние игры при этом сохраняется. Клавиши разработчика:
`P` — пауза, `[` `]` — скорость, `.` — шаг на один кадр.

## Проверки

```sh
node live/tune.cjs          # демо-заставка без браузера + проверка инвариантов уровня (selfCheck)
node tools/difficulty.cjs --seeds 1 --profiles average --runs 3   # три забега подряд с мета-прокачкой, статистика по этажам
node tools/difficulty.cjs --seeds 1-160 --profiles average --check   # средний игрок на 160 сидах: давление по этажам и приёмка боссов
node tools/difficulty.cjs --seeds 1-80 --profiles average,expert --check   # общая приёмка нормальной сложности
node tools/brawlcheck.mjs
node tools/spellcheck.mjs
node tools/bossvis.mjs
```

`brawlcheck` проверяет плотный бой с элитой при всех масштабах: пересечения текста, отступ от имени, положение полученного урона, порядок имени и полосы HP, вспышки попаданий. Кадры и отчёт сохраняются в `frames/brawl/`; нужен Playwright из инструментов ref2game.

`spellcheck` проверяет вихрь, огненный шар и взрыв: пиксельную сетку, маску разведанного пола и стен, ступени прозрачности, повторяемость кадра и срок подпалины. Полосы из шести увеличенных кадров и отчёт сохраняются в `frames/spells/`; нужен тот же Playwright.

`bossvis` проверяет видимость короны Королевы и кладок в игровом масштабе: сравнивает кадр с каждым новым спрайтом и без него. Кадры сохраняются в `frames/bossvis/`.

Для длинной приёмки `difficulty.cjs --json-out frames/balance.json` сохраняет каждый завершённый забег. С теми же параметрами и версией симуляции `--resume frames/balance.json` продолжает недостающие сиды, а `--from-json frames/balance.json` повторно считает таблицы и полосы без запуска ботов. `--check` отклоняет зависшие забеги, пропущенные или повторённые сиды и неполное число забегов. Для смертности финального босса нужны 160 сидов; на меньшей выборке проверка явно сообщает, что эта полоса ещё не оценена. `--quiet` ограничивает запуск двумя процессами с низким приоритетом.

Для настройки только приёмов или чисел босса `--snapshots frames/boss-campaigns` сохраняет состояние симуляции и RNG бота на входе в каждый этаж. `--resume frames/balance.json --snapshots frames/boss-campaigns --replay-floor 8` переигрывает финальный этаж, сохраняя результаты походов, закончившихся раньше. Число — первый этаж с изменёнными правилами; при изменениях генерации карты, поведения бота или более ранних правил нужен полный прогон.

## Устройство

| Путь | Что там |
|---|---|
| `live/` | игра: `sim.js` (детерминированная симуляция, 120 Гц), `dungeon.js` (генератор этажей), `data.js` (контент и баланс), `scene.js` / `monsters.js` / `hud.js` (отрисовка), `gl.js` / `lib.js` (движок) |
| `live/assets/` | готовые к движку текстуры (генерируются из `art/gen`) |
| `art/gen/` | исходный арт, сгенерированный ИИ; промпты в `art/prompts/`, стиль в `art/style_bible.txt` |
| `study/` | разбор концепта: палитра, значения, тайлы |
| `tools/` | скрипты для нарезки ригов, правки спрайтов и проверок |
| `TASKS.md` | открытые задачи: баги, замечания и улучшения |
| `TASKS_COMPLETED.md` | сделанные задачи с описанием, что и как сделано |

## Концепт

<img src="ref.png" alt="Концепт-арт" width="640">

Концепт-арт, по которому сделана игра: стиль, палитра, масштаб и композиция кадра.

Проект сделан с помощью Claude Code и скилла **ref2game**. Арт создан генератором изображений по концепту и стайл-гайду.
Анимация, свет, эффекты и геймплей написаны кодом.
